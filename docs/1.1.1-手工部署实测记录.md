# Kunlun 1.1.1 简化结构手工部署实测记录

本文记录 `1.1.1` 简化结构在 Kylin Linux V10 `x86_64` 虚拟机上的实际手工部署结果。操作步骤以 [V1 手工版](V1-手工版.md) 为准。

## 1. 结论

`1.1.1` 核心手工部署成功：

- 外层和包内 SHA256 校验通过；
- 简化目录创建成功，未创建 `packages/releases/current/state/kunlun.env`；
- Docker 29.7.0 和 Compose v5.4.0 离线安装成功；
- Docker data-root 为 `/opt/Kunlun/docker/data`；
- 六个独立镜像 tar 导入成功且全部为 `linux/amd64`；
- MySQL、Redis、RabbitMQ、MinIO 全部 `running/healthy`；
- backend/frontend `1.1.1` 启动成功，操作者确认业务部署成功；
- 中间件数据已经写入四个固定 data 目录。

## 5. 实际执行阶段

本次目标机按以下顺序手工执行：

1. `sha256sum -c` 校验外层压缩包。
2. 解压后校验包内 `SHA256SUMS`，共 38 条。
3. 检查 manifest 和简化目录结构。
4. 检查 systemd、架构、内存、磁盘和端口。
5. 执行 `scripts/init-layout.sh` 建立 `/opt/Kunlun`。
6. 校验 Docker/Compose 离线介质。
7. 安装 Docker 静态二进制、Compose 插件、daemon.json 和 systemd unit。
8. 验证 Docker Root Dir。
9. 安装两份 Compose、九个运维脚本和六个独立镜像 tar。
10. 校验并逐个 `docker load` 六张镜像。
11. 执行 `init-dirs.sh` 初始化四个数据目录权限。
12. 创建外部网络 `kunlun-net`。
13. 启动 middleware Compose 并执行 `check-middleware.sh`。
14. 启动 app Compose并完成业务确认。

完整命令保存在 [V1 手工版](V1-手工版.md)，本记录不重复保存明文密码或 Compose 展开内容。

## 8. 账号和密码映射

本版本使用一套共享密码，实际值不写入文档。账号映射：

| 组件 | 账号 | 密码 |
|---|---|---|
| MySQL 管理 | `root` | Compose 内共享密码 |
| MySQL 业务 | `offline_app` | Compose 内共享密码 |
| Redis | 无独立用户名 | Compose 内共享密码 |
| RabbitMQ | `admin` | Compose 内共享密码 |
| MinIO | `minioadmin` | Compose 内共享密码 |

只能在目标机 root 会话中查看，不得粘贴回聊天或日志：

```bash
awk -F'"' '/^x-kunlun-shared-password:/ {print $2}' \
  /opt/Kunlun/middleware/compose.middleware.yml
```

## 9. 一键入口

已安装机器启动全部服务：

```bash
bash /opt/Kunlun/scripts/start.sh
```

全新机器的一键初始化脚本已经加入源码：

```text
deploy/scripts/install-bootstrap.sh
```

它负责包内校验、目录、Docker、Compose、六镜像、数据权限、网络、全部服务启动和业务健康验收。该脚本是在本次手工包生成后新增，必须进入新的 `r2` 交付包并在另一台全新虚拟机复验，不能修改本次已冻结的 tar。
